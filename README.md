# CBH Go — ระบบนำทาง 3 มิติ โรงพยาบาลชลบุรี (Full Admin Edition)

ระบบนำทางผู้ป่วยและญาติภายในโรงพยาบาลชลบุรีแบบ 3 มิติ พร้อม **Visual 3D Admin Studio** ที่ช่วยให้ผู้ดูแลระบบสามารถสร้างตึกใหม่ ปรับแก้เส้นทางเดิน ปิดซ่อมเส้นทางชั่วคราว และย้ายตำแหน่งคลินิก/หน่วยงานได้ทันทีโดยไม่ต้องเขียนโค้ด

## ฟีเจอร์สำหรับผู้ดูแลระบบ (Full Admin)
- กดปุ่มไอคอนประแจ (มุมขวาบนของการ์ดค้นหา) รหัสผ่านเริ่มต้น: `cbh2026`
- **จัดการตึก/อาคาร:** คลิกวางอาคารใหม่บนแผนที่ 3D ปรับขนาด สี และชื่อได้แบบเรียลไทม์
- **จัดการทางเดิน/ถนน:** ปักจุดทางแยก (Node) ลากเส้นเชื่อมทางเดิน และกดเปิด/ปิดเส้นทางที่กำลังปรับปรุงได้ทันที
- **ย้ายหน่วยงาน/คลินิก:** ย้ายคลินิกไปยังอาคารหรือชั้นใหม่ได้ทันที พร้อมรองรับการซิงค์ขึ้น Google Sheets (`Code.gs`)
